# Add-on: FAQ

Preguntas frecuentes con `<details>` nativo, sin JavaScript.

## Instalación

1. Copia esta carpeta a `src/addons/faq/` del proyecto cliente.
2. Agrega `faq: true` en `siteConfig.features` de `src/data/site.ts`, en la posición donde quieres que aparezca.
3. Edita `faqs` en `src/data/site.ts` con las preguntas reales del cliente.

No hace falta tocar `index.astro` ni ningún componente existente.
