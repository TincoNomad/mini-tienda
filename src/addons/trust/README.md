# Add-on: Trust

Franja de confianza con garantía, envíos, pagos y devoluciones.

## Instalación

1. Copia esta carpeta a `src/addons/trust/` del proyecto cliente.
2. Agrega `trust: true` en `siteConfig.features` de `src/data/site.ts`, en la posición donde quieres que aparezca.
3. Edita `trustItems` en `src/data/site.ts` con los datos reales del cliente.

No hace falta tocar `index.astro` ni ningún componente existente.
